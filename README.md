# 🎓 Studiously AI

### Your AI-Powered Personal Study Assistant

Studiously AI is an AI-powered study assistant built to make learning easier, smarter, and more interactive. It helps students understand topics, practise questions, test their knowledge, and learn with an AI tutor.

🌐 **Live Demo:** https://studiously-ai-ckmn5bfefbnp4jvhyes4uw.streamlit.app/

## ✨ Features

* 📚 **AI Study Notes:** Generate study notes for academic topics.
* 📝 **Practice Questions:** Create practice questions to reinforce learning.
* 🧠 **Quiz Mode:** Test your understanding with interactive quizzes.
* 🤖 **AI Tutor:** Ask questions and get AI-generated explanations.
* 📄 **PDF Export:** Download study material for revision.

## 🛠️ Tech Stack

* Python
* Streamlit
* Google Gemini API
* ReportLab

## 🚀 How to Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/sahanabaskar28/studiously-ai.git
cd studiously-ai
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Configure your Gemini API key

Set your `GEMINI_API_KEY` as an environment variable. Never publish your API key in your source code or GitHub repository.

### 4. Run the application

```bash
streamlit run studiously_app.py
```

## 🔐 Security

Keep your Gemini API key private. For deployment, configure it through Streamlit Community Cloud's Secrets settings.
